# رشد — بانک اطلاعات کسب‌وکار

نسخهٔ مستقل و فقط‌خواندنی برای ارائه به کارفرما؛ بدون نیاز به کامپیوتر شخصی، SQL Server، سرور برنامه یا مدل هوش مصنوعی.

شامل ۹۰۳ مجوز، ۹۲ مشتری، ۹۲ پیگیری و اطلاعات ۳۱ استان. جست‌وجو، دراپ‌دان فیلتر ستون‌ها، جزئیات مجوز، CSV و تم روشن/تاریک فعال است. فایل SQLite همراه سایت میزبانی می‌شود و SQL.js جست‌وجو را داخل مرورگر انجام می‌دهد.

## انتشار GitHub Pages

در Settings → Pages، گزینهٔ Deploy from a branch را انتخاب کنید: branch `main` و پوشهٔ `/`.

همهٔ فایل‌های اجرایی داخل `root/` هستند و ساخت مجدد یا نصب وابستگی لازم نیست. اطلاعات، تصویر مستقلی از زمان تهیهٔ نسخه است؛ ثبت یا ویرایش و همگام‌سازی با نسخهٔ محلی ندارد.
